# Security / 安全

DrawerBar is a developer preview with no security support SLA. Accessibility is a broad local macOS permission. Review the source before granting access. Current preview builds are ad-hoc signed, not Developer ID signed or notarized.

For a suspected vulnerability, do not publish credentials, personal recordings, unredacted diagnostics, or an exploit containing private data in a public issue. Use GitHub's **Report a vulnerability** option if available; otherwise open a minimal issue requesting a private reporting channel, without sensitive details. There is no automatic update channel; check Releases manually.

小屉为开发预览版，没有安全支持 SLA。辅助功能是 macOS 的广泛本机权限，授权前请审阅源码。当前构建使用临时签名，没有 Developer ID 签名或 Apple 公证。

发现漏洞时，不要在公开 Issue 中上传凭证、个人录屏、未脱敏日志或含私密数据的利用代码。如果 GitHub 提供“Report a vulnerability”请使用该入口；否则只提交不含敏感细节的 Issue，请维护者提供私密渠道。目前无自动更新，请主动检查 Releases。
