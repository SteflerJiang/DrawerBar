小屉 / DrawerBar — 开发预览版

要求 Apple Silicon（M1 或更新）与 macOS 14+。
将应用拖到“应用程序”，推出映像，再打开安装副本。
当前为临时签名，没有 Developer ID 签名或 Apple 公证。
请先核对来源、源码和校验值，再决定是否信任。
Apple 官方打开说明：https://support.apple.com/zh-cn/102445

在“系统设置 → 隐私与安全性 → 辅助功能”授权。
屏幕录制是可选项，用于显示原菜单栏图像；未授权时使用应用图标。
每位使用者需在自己的 Mac 上授权，临时签名重编译后旧授权可能失效。

在“图标整理”点击即可收起 / 显示；点击菜单栏抽屉或按 Command-Shift-Space 展开单行浮栏。
支持原点击 / 右键菜单、固定、自动收起、全局快捷键和四档间距。
间距选中即保存，但 macOS 26 已运行应用需要重开后更新外观。
仅在用户主动开启并明确勾选应用后重开；不强制退出、不注销。

中文名“小屉”，英文名“DrawerBar”，跟随 macOS 应用语言设置。
开发预览版；其他系统版本、刘海和多屏仍需进一步测试。
没有账号、联网、遥测或自动更新。
完整说明及各版本限制：https://github.com/SteflerJiang/DrawerBar
