# 小屉 · DrawerBar

**简体中文** · [English](README.md)

**[下载 DMG 安装包（推荐）](<https://github.com/SteflerJiang/DrawerBar/releases/download/v0.1.12/DrawerBar-0.1.12-AppleSilicon.dmg>)** · **[下载 ZIP](<https://github.com/SteflerJiang/DrawerBar/releases/download/v0.1.12/DrawerBar-0.1.12-arm64.zip>)** · [v0.1.12 预览版说明](https://github.com/SteflerJiang/DrawerBar/releases/tag/v0.1.12)

给 Mac 菜单栏加一个小抽屉。常用图标留在外面，偶尔用的收进单行浮栏。

原生 SwiftUI + AppKit，面向 Apple Silicon，支持简体中文和英文。无账号、遥测、云服务或第三方运行时依赖。

**当前为开发预览版**：源码面向 macOS 14 及以上；实机测试环境为 M1、macOS 26.6.2、单屏无刘海。其他系统版本、刘海屏和多屏尚未完成兼容性验收。具体范围见[测试与限制](docs/TESTING.md)。

## 安装

1. 准备 Apple Silicon Mac（M1 或更新芯片），系统为 macOS 14 或更新版本。
2. 打开 DMG，把 **DrawerBar.app** 拖到 **Applications / 应用程序**。ZIP 解压后同样移到应用程序。中文 Finder 可能显示本地化名称“小屉”。
3. 推出磁盘映像，从应用程序打开。保留一份安装副本；更新前先退出旧版本。
4. 未公证的预览版可能被系统拦截。先核对来源、源码、版本说明和校验值；确认信任后，按照 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在“系统设置 → 隐私与安全性”中选择“仍要打开”。公司管理的 Mac 可能禁止安装。不要关闭 Gatekeeper 或 SIP。
5. 在“系统设置 → 隐私与安全性 → 辅助功能”允许小屉，用于识别、移动和操作其他应用的菜单栏图标。
6. “屏幕录制”（部分系统显示“屏幕与系统音频录制”）为可选权限，用于显示原菜单栏图像。不授权时使用应用图标替代。系统可能要求退出并重新打开应用。

每位用户都需要在自己的 Mac 上授权。临时签名的二进制重新构建后，系统可能不再信任旧授权记录；开关开启不一定代表当前程序已被系统信任。见[常见问题](docs/TROUBLESHOOTING.md)。

## 使用

### macOS 27 适配

本地源码增加了 macOS 27 的独立适配路径：通过辅助功能识别来源应用，用 MenuBarAgent 的临时显示白名单收起图标，不再依赖旧版独立窗口和超宽分隔线。从 `/Applications/DrawerBar.app` 运行；重新构建后的辅助功能授权可能需要移除旧条目再添加。屏幕录制不是这条隐藏路径的必需权限。

本地排序版会通过“授权菜单栏排序文件”让你选择 `~/Library/Group Containers/com.apple.MenuBar/Library/Preferences/com.apple.MenuBar.plist`，只授权这个文件；修改前备份到 `~/Library/Application Support/MenuBarStudio/native-layout-original.plist`。小屉入口始终靠左，隐藏后左侧图标向右补位，显示前入口先左移留空，再将目标放在入口右边第一位。排序只改入口与目标应用的数值，保留其他应用的相对顺序和系统模块设置。当前双屏环境已通过三轮隐藏/显示实测，具体程序哈希和覆盖限制见 `docs/TESTING.md`；尚未发布新 Release。

此路径按应用管理，同一应用的多个图标一起切换；浮栏暂用应用图标。访问菜单栏右侧系统区域时会暂时展开，避免阻挡通知中心。部分 Apple 动态模块可能在限制期间暂时消失，解除限制后恢复；不卸载或改写系统模块设置。退出或进程结束会释放临时白名单，已保存的排序仍会保留。使用的系统私有接口可能随系统更新变化，入口会先检查可用性。

- **图标整理**：点击图标即可在“常驻菜单栏”和“已收进小屉”两区切换，也可跨区拖动。新图标默认常驻。系统项目在 macOS 系统设置中管理。
- **展开浮栏**：点击菜单栏的透明空心抽屉，或按 **⌘⇧Space**。所有隐藏图标单行展示；超出屏幕可用宽度时横向滚动，不自动换行。
- **使用原图标**：左键调用原操作；来源应用支持时，右键打开原右键菜单。当前源码只会临时把目标图标放回菜单栏，原菜单关闭后再收起。失败会提示，避免悄悄保存错误分类。
- **浮栏排序**：在收起区拖动图标排序，也可以右键“向前移动 / 向后移动”。常驻图标的系统顺序用 macOS 的 **按住 Command 拖动**调整。
- **收起浮栏**：按 Esc、点击外部，或鼠标离开后等待设定时间（默认 1.5 秒）。固定按钮可保持展开，操作原菜单期间暂停自动收起。
- **右键小屉入口**：打开设置、暂停 / 继续整理、查看引导或退出。暂停会临时显示图标并保留分类；正常退出会释放隐藏边界。
- **通用设置**：快捷键可选 **⌘⇧Space**、**⌘⇧B** 或关闭；被占用时明确提示。可开启登录时启动，深浅色跟随系统。
- **恢复图标整理默认配置**：清除分类和浮栏顺序前需要确认；保留间距、快捷键和登录时启动设置，并保存恢复前的本机备份。

### 浮栏外观

允许屏幕录制后，浮栏跟随菜单栏的背景配色，原始图标按原尺寸显示，不再使用独立卡片底色或边框。网速、未读数等宽图标保留原宽度。未授权时使用系统材质与应用图标替代。小屉为空时显示紧凑提示，点击整行即可打开图标整理。

### 图标移动

macOS 26 的控制中心托管图标使用单一路由。显示时先在入口旁让出空间，再将目标放入最左侧首个常驻位置；隐藏时保持其他隐藏图标收起。0.1.12 实机回归的 34 次切换均一次成功，检查的录屏过渡帧未复现此前的重叠或闪出。详见[耗时与测试范围](docs/TESTING.md)。其他系统与宿主保留兼容路径。

### 图标间距

支持“默认间隔、较小间隔、小间隔、无间隔”四档，选中即保存，无“应用”按钮、无二次确认。支持撤销和恢复系统默认。

**保存成功不代表已有图标立即改变外观。** macOS 26 会缓存已运行应用的间距，图标需要在所属应用重开后更新。你可以明确勾选允许重开的应用，再开启切换间距时自动重开；这可能短暂中断连接或任务，不会强制退出，也不会注销。新配置不会预选应用。系统图标仍由系统控制，“无间隔”也不保证实际间隙为零。目前尚未实现完全不重开应用的即时更新。

修改范围是当前用户、当前主机的 `NSStatusItemSpacing` 和 `NSStatusItemSelectionPadding`。修改前自动备份原值（包括未设置状态）；撤销前会检查其他工具是否又改过，避免静默覆盖。退出后主动设置的间距保留，卸载前可先恢复。

### 中英文与产品名称

同一应用在简体中文下叫 **小屉**，英文下叫 **DrawerBar**。界面、菜单、帮助、错误、辅助功能标签、应用显示名及录屏权限说明均有对应语言。其他语言回退英文；来源应用的名称和原生菜单跟随来源应用自身语言。

默认跟随 macOS 语言。也可在“系统设置 → 通用 → 语言与地区 → 应用程序 → +”中选择 DrawerBar，指定“简体中文”或“English”，重新打开后生效。下载文件统一使用 DrawerBar 名称，便于国内外分享。内部应用标识和原有配置目录保留。

## 隐私与本机数据

图标图像与菜单栏小范围颜色采样仅在本机内存中处理，不保存、不上传。应用没有联网、账号、遥测或自动更新代码。辅助功能与录屏权限属于 macOS 本机权限。

配置与有限的诊断记录位于 `~/Library/Application Support/MenuBarStudio/`。为了兼容旧用户，内部 Bundle ID 保留 `local.menubarstudio.app`。诊断可能包含来源应用标识、窗口几何、操作类型及耗时，不包含截图、菜单正文或输入文字。公开提交前请自行检查并脱敏。详见[隐私说明](docs/PRIVACY.md)。

## 更新与卸载

更新时先退出小屉，替换应用程序中的应用，再打开。授权状态异常时按常见问题处理，不必重置整台 Mac 的权限。

卸载前可恢复原间距 / 默认间距、关闭登录时启动，再正常退出并移到废纸篓。可选的配置清理方法见[常见问题](docs/TROUBLESHOOTING.md)。不会清除其他应用的数据。

## 源码构建

要求 Apple Silicon、macOS 14+ 和 **Swift 6** 工具链（Xcode 或兼容命令行工具）。无第三方包依赖。

```sh
git clone https://github.com/SteflerJiang/DrawerBar.git
cd DrawerBar
swift run CoreChecks
python3 scripts/check-localizations.py
APP_BUNDLE_NAME=DrawerBar zsh scripts/build.sh
APP_BUNDLE_NAME=DrawerBar zsh scripts/package-dmg.sh
```

默认输出到仓库同级的 `outputs/`；可通过 `BUILD_OUTPUT_DIR` 指定目录。本机构建默认文件名“小屉.app”，加 `APP_BUNDLE_NAME=DrawerBar` 使用国际文件名，内部程序与 Bundle ID 不变。DMG 脚本直接打包现有应用，不重新编译。

核心检查不会修改系统间距。CI 负责 macOS 构建和语言资源检查；真实菜单栏行为仍需已解锁的桌面、用户授权和实机验收。源码构建使用临时签名，重编译可能影响旧授权。
